# Responsive Personal Portfolio Website

## Veda Technology Major Project

A modern, professional and fully responsive personal portfolio website built using HTML5, CSS3 and JavaScript.

---

## Project Overview

The Responsive Personal Portfolio Website is designed to present a developer's professional profile, skills, projects, education, experience and contact information.

The website is responsive and works across:

- Desktop
- Laptop
- Tablet
- Mobile

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- VS Code
- Git
- GitHub

---
